# 팔로우 화면 UI 레이아웃 — 리그 / 팀 / 선수 선택

사용자가 관심 있는 리그, 팀, 선수를 단계별로 선택하는 3단계 온보딩 화면. 리그 선택 → 팀 선택 → 선수 선택 순으로 진행하며, 각 단계는 동일한 레이아웃 구조를 공유한다.

---

## 공통 레이아웃 (3단계 동일)

```
┌──────────────────────────────┐
│ [헤더]                        │
│   · 화면 제목 (단계별 상이)    │
│   · 닫기/뒤로가기 버튼         │
├──────────────────────────────┤
│ [검색창]                      │
│   · 리그/팀/선수 이름 검색     │
├──────────────────────────────┤
│ [항목 목록] (스크롤)           │
│   · 선택 가능한 카드 나열      │
│   · 선택 시 선택 상태 표시     │
│   · 선택한 순서대로 번호 표시  │
│   · 부스트 가능 항목 뱃지 표시 │
├──────────────────────────────┤
│ [단계 인디케이터]              │
│   · 현재 단계 표시 (1/2/3)    │
│   · 이전 버튼 / 다음·완료 버튼 │
└──────────────────────────────┘
```

검색창 포커스 시 항목 목록 영역이 검색 결과로 대체됨.
검색 결과 없을 때는 빈 상태 안내 문구 표시.

---

## 선택 상태 동작

### 선택 순서 번호
- 카드를 선택하면 선택한 순서대로 번호(1, 2, 3…)가 카드에 표시됨
- 중간 항목을 해제하면 이후 번호는 자동으로 당겨짐 (e.g. 1·2·3에서 2 해제 → 1·2)
- 선택 해제 시 번호 사라짐

### 단계 이동 시 선택 유지
- 이전/다음 단계로 이동해도 각 단계의 선택 상태가 그대로 유지됨
- 리그 선택 후 팀으로 넘어갔다가 다시 리그로 돌아와도 선택 내용 보존
- 선택 순서 번호도 함께 유지됨

---

## 1단계: 리그 선택

**헤더 제목**: "Back Your League"

### 리그 카드 항목
| 위치 | 항목 |
|------|------|
| 좌측 | 리그 로고 이미지 |
| 중앙 | 리그명 |
| 중앙 하단 | 리그 슬러그 (약어, e.g. "lck") |
| 우측 상단 | 부스트 가능 뱃지 (해당 시) |
| 우측 | 선택 순서 번호 (선택 시) |

### 선택 제한
- 최소 1개 / 최대 5개

---

## 2단계: 팀 선택

**헤더 제목**: "Back Your Team"

### 팀 카드 항목
| 위치 | 항목 |
|------|------|
| 좌측 | 팀 로고 이미지 |
| 중앙 | 팀명 |
| 중앙 하단 | 팀 약어 (initial, e.g. "T1") |
| 우측 상단 | 부스트 가능 뱃지 (해당 시) |
| 우측 | 선택 순서 번호 (선택 시) |

### 선택 제한
- 최소 1개 / 최대 10개

---

## 3단계: 선수 선택

**헤더 제목**: "Follow Players"

### 선수 카드 항목
| 위치 | 항목 |
|------|------|
| 좌측 | 선수 프로필 이미지 |
| 중앙 상단 | 선수 닉네임 |
| 중앙 하단 | 소속 팀명 + 팀 로고 |
| 우측 | 선택 순서 번호 (선택 시) |

### 선택 제한
- 최소 없음 / 최대 20개

### 완료 버튼
- "Done" 버튼 탭 시 리그·팀·선수 선택 내용 일괄 저장 후 메인으로 이동

---

## 단계 인디케이터

```
[← 이전]  ● ○ ○  [다음 →]
           리그 팀 선수
```

| 단계 | 이전 목적지 | 다음 목적지 |
|------|------------|------------|
| 리그 (1) | 메인 (`/`) | 팀 선택 |
| 팀 (2) | 리그 선택 | 선수 선택 |
| 선수 (3) | 팀 선택 | 완료 → 메인 |
