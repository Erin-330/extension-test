# 랭킹 화면 UI 레이아웃

월간 스트릭 기준으로 전체 사용자의 순위를 보여주는 화면. 내 순위 확인, 상위 5명 포디움, 등급별 랭킹 목록 순으로 구성된다. 항목 클릭 시 해당 사용자의 상세 정보를 모달로 볼 수 있다.

---

## 전체 레이아웃

```
┌──────────────────────────────┐
│ [헤더]                        │
│   · 제목: "랭킹"              │
│   · 좌측: 닫기 버튼 (프로필로) │
│   · 우측: 정보 아이콘          │
├──────────────────────────────┤
│ [월 선택]                     │
│   · 조회할 월 선택 드롭다운    │
├──────────────────────────────┤
│ [상위 5명 섹션]               │
│   (스크롤 영역 시작)           │
├──────────────────────────────┤
│ [내 랭킹 섹션]                │
├──────────────────────────────┤
│ [등급별 랭킹 섹션]            │
│   · 등급마다 반복             │
└──────────────────────────────┘
```

> **레이아웃 순서**: 상위 5명 섹션이 내 랭킹 섹션보다 위에 표시된다.

---

## 헤더

| 위치 | 항목 |
|------|------|
| 중앙 | "랭킹" 텍스트 |
| 좌측 | 닫기 버튼 → 프로필 화면으로 이동 |
| 우측 | 정보 아이콘 → 랭킹 기준 안내 모달 |

---

## 월 선택 드롭다운

- 선택 가능한 월 목록 표시
- 선택 변경 시 해당 월 랭킹 데이터 재조회

---

## 내 랭킹 섹션

로그인한 사용자 본인의 현재 순위를 강조 표시.

| 위치 | 항목 |
|------|------|
| 좌측 | 순위 번호 |
| 좌측 | 프로필 이미지 |
| 중앙 | 닉네임 |
| 중앙 | 등급 배지 |
| 우측 | 현재 스트릭 수 |
| 우측 하단 | 최장 연승 수 |
| 우측 하단 | 예상 보상 에너지 |

---

## 상위 5명 섹션

- **Rive 그래프(`rank-rive-graph`)만 표시** — 포디움 아이템 목록 없음
- 구현 상세(Rive 파일 URL, Artboard, State Machine, 데이터 바인딩 등) → `.claude/rank-rive-graph.md` 참고

---

## 등급별 랭킹 섹션 (6위~)

등급마다 하나의 섹션으로 구성. 섹션은 등급 헤더 + 유저 목록 순.

### 등급 헤더
| 위치 | 항목 |
|------|------|
| 좌측 | 등급명 |
| 우측 | 해당 등급 예상 보상 에너지 |

> **스트릭 그래프 막대**: 등급 헤더 아래 막대(bar) 그래프는 표시하지 않는다.

### 랭킹 목록 행 (각 유저)
| 위치 | 항목 |
|------|------|
| 좌측 | 순위 번호 |
| 좌측 | 프로필 이미지 |
| 중앙 | 닉네임 |
| 중앙 | 등급 배지 |
| 우측 | 현재 스트릭 수 |
| 우측 | 최장 연승 수 |
| 우측 하단 | 예상 보상 에너지 |

- 내 항목은 별도 강조 표시
- 항목 클릭 시 상세 모달 오픈

---

## 랭킹 상세 모달 (항목 클릭 시)

화면 하단에서 슬라이드업으로 표시.

| 위치 | 항목 |
|------|------|
| 상단 중앙 | 프로필 이미지 (크게) |
| 중앙 | 닉네임 |
| 중앙 | 등급 배지 |
| 하단 | 현재 스트릭 수 |
| 하단 | 최장 스트릭 수 |
| 하단 | 예상 보상 에너지 |
| 하단 | 닫기 버튼 |

---

## 랭킹 기준 안내 모달 (정보 아이콘 클릭 시)

동점 시 순위 결정 기준 안내 텍스트 표시.
